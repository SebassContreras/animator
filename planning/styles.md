# Styles

- **Hard rule:** English for every file and every on-screen text.
- **Default:** each video picks one named style from `skills/lienzo-art-direction/references/styles.md` and keeps its own palette in `videos/<slug>/palette.json` (roles with base / shadow / highlight tones).
- **Default:** text contrast ≥ 4.5:1 and phone-readable sizes (`skills/lienzo-storyboard/references/craft.md`).
- **Anti-preference:** videos that look programmed (flat defaults, linear motion, frozen frames) instead of designed.
