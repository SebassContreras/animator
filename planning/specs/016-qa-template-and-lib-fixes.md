## Requirements
- R1 (`F-01`): `videos/_template/scene.gen.cjs:10` resolves `../brand.lock.json` first and falls back to local `./brand.lock.json` only when `../brand.lock.json` does not exist (matching standalone `videos/_template/` execution), and `skills/lienzo-storyboard/SKILL.md:15` excludes `brand.lock.json` when copying `videos/_template` to `videos/<brand>/<video>`.
  - Partitions:
    - Brand video folder `videos/<brand>/<video>/` where `../brand.lock.json` exists and no local `brand.lock.json` exists → loads `../brand.lock.json`.
    - Brand video folder `videos/<brand>/<video>/` where both `../brand.lock.json` and an accidental local `brand.lock.json` exist → `../brand.lock.json` wins.
    - Standalone `videos/_template/` (no `../brand.lock.json`, local `videos/_template/brand.lock.json` exists) → falls back to `./brand.lock.json`.
  - Invariant: a video created in `videos/<brand>/<video>/` always inherits `videos/<brand>/brand.lock.json`.
- R2 (`F-13`): `videos/_template/scene.gen.cjs:6-11,25` loads `lock` before reading canvas dimensions and sets `const { width: W, height: H, duration: D, fps: FPS } = lock.canvas;` and `fps: FPS` in `scene` (`videos/_template/scene.gen.cjs:25`).
  - Partitions: `_template/brand.lock.json` (`1080×1920`, `duration: 6`, `fps: 30`); custom brand lock (`1920×1080`, `duration: 12`, `fps: 60`).
  - Invariant: generated `scene.json` top-level `size`, `duration`, and `fps` match `lock.canvas` `[width, height]`, `duration`, and `fps`.
- R3 (`F-02`): `lib/objects.cjs:20-44` (`metricCard`) strips card-specific keys (`bgColor`, `border`, `titleY`, `titleFont`, `titleSize`, `titleWeight`, `titleColor`, `counterY`, `counterH`, `counterSize`, `counterColor`, `glow`) from `extra` before passing the remaining `groupExtra` (e.g. `shot`, `name`, `anim`, `tracks`, `opacity`) to `group(...)` at `lib/objects.cjs:43`.
  - Partitions: `extra` with card styling keys + `shot: "s3"`; `extra` with only `shot: "s1"`; `extra` omitted.
  - Invariant: the returned `group` object never contains `bgColor`, `border`, `titleY`, `titleFont`, `titleSize`, `titleWeight`, `titleColor`, `counterY`, `counterH`, `counterSize`, `counterColor`, or `glow` as top-level properties on the group, while child `bg`, `titleEl`, and `counterEl` still receive their configured values and the group retains `groupExtra` (`shot`, `anim`, `tracks`).
- R4 (`F-18`): `lib/brand.cjs:43-51` (`brandFonts(lock)`) returns `{ heading, body, ...(mono ? { mono } : {}), ...(accent ? { accent } : {}) }` (`mono` picked at `Math.min` weight, `accent` at `Math.max` weight), and `lib/scene.cjs:14` (`fontOf(extra)`) resolves `(extra.font && fonts[extra.font]) || (extra.font === "body" ? fonts.body : fonts.heading)`.
  - Partitions: lock with only `heading` + `body` (returns `{ heading, body }` byte-identical to previous output); lock with `heading`, `body`, `mono`, and `accent`; lock with no fonts (`DEFAULT_FONTS`); `label` with `extra.font: "mono"`, `"accent"`, `"body"`, `"heading"`, or omitted.
  - Invariant: when a brand declares only `heading` and `body`, `brandFonts(lock)` output is unchanged; when `mono` or `accent` is declared, `label(..., { font: "mono" })` uses `fonts.mono`.
- R5 (`F-19`): `lib/environment.cjs:5-13` accepts `extra = {}` in `sea(id, frame, deep, light, name = "Deep sea", extra = {})` (`lib/environment.cjs:5-7`) and `particles(id, name, box, { count, drift, seed, size, color, opacity }, extra = {})` (`lib/environment.cjs:10-13`), merging `...extra` into the returned element descriptor.
  - Partitions: `extra` omitted (byte-identical to previous output); `extra: { shot: "s1", opacity: 0.8 }` on both `sea` and `particles`; `extra.fill` on `sea` (preserves gradient while merging `extra.fill`).
  - Invariant: omitting `extra` produces output byte-identical to existing behavior; passing `{ shot: "s1" }` attaches `shot: "s1"` to the returned element.
- R6 (`F-20`): In `lib/scene.cjs:41-49`, `label` omits `anim.out` when `extra.out === false`, and in `lib/scene.cjs:54-55`, `nativeShot(id, name, start, end, camera, transition)` includes `...(transition ? { transition } : {})` when `transition` is provided and updates the comment at line 54.
  - Partitions: `label` with `extra.out` omitted (includes `anim.out` as before); `label` with `extra.out: false` (omits `anim.out`, retains `anim.in`); `nativeShot` with `camera` and `transition` omitted; `nativeShot` with `camera` only; `nativeShot` with `camera: undefined` and `transition: { kind: "fade", duration: 0.4 }`.
  - Invariant: existing `label` and `nativeShot` calls without the new arguments remain byte-identical.
- R7 (`F-24`): `lib/brand.cjs:10-13` exports `brandNotices(inspect)` (or `checkBrandLock` / `brandLock` helper) returning any `inspect.notices` array from `project_inspect` so `skills/lienzo-storyboard/SKILL.md:20` prints warnings to `stderr` when brand fonts or weights are missing in Lienzo.

## Design
- D1 (R1, R2): In `videos/_template/scene.gen.cjs:6-15,25`, resolve `parentLock = path.join(__dirname, "../brand.lock.json")` before `localLock = path.join(__dirname, "brand.lock.json")`, load `lock = checkBrandLock(require(fs.existsSync(parentLock) ? parentLock : localLock))`, destructure `const { width: W, height: H, duration: D, fps: FPS } = lock.canvas;`, and set `fps: FPS` in `scene` (`comment cites (016/D1)`).
- D2 (R3): In `lib/objects.cjs:20-44`, destructure `{ bgColor, border, titleY, titleFont, titleSize, titleWeight, titleColor, counterY, counterH, counterSize, counterColor, glow, ...groupExtra } = extra` and pass `groupExtra` to `group(id, x, y, w, h, [bg, titleEl, counterEl], groupExtra)` (`comment cites (016/D2)`).
- D3 (R4): In `lib/brand.cjs:43-51`, pick `mono = pick("mono", Math.min)` and `accent = pick("accent", Math.max)` and spread them into the returned object when defined; in `lib/scene.cjs:14`, update `fontOf` to `(extra) => (extra.font && fonts[extra.font]) || fonts[extra.font === "body" ? "body" : "heading"]` (`comment cites (016/D3)`).
- D4 (R5): In `lib/environment.cjs:5-13`, add `extra = {}` to `sea` and `particles` and spread `...extra` into the returned objects (`comment cites (016/D4)`). Update `videos/pulse-metrics/speed/scene.gen.cjs:20-22` and `videos/pulse-metrics/chaos/scene.gen.cjs:19` to pass `{ shot: "s1" }` / `{ shot: "s2" }`.
- D5 (R6): In `lib/scene.cjs:41-55`, conditionally omit `out` in `label` when `extra.out === false`, and add `transition` parameter to `nativeShot(id, name, start, end, camera, transition)` (`comment cites (016/D5)`).
- D6 (R7): In `lib/brand.cjs`, export `brandNotices = ({ notices = [] } = {}) => notices`, and list `brandNotices` in `skills/lienzo-animate/SKILL.md` under `### Start from lib/` (`tests/skills/lib-list.test.cjs` guard) (`comment cites (016/D6)`).

### Trade-offs & Mitigations
- D1. Pros: eliminates silent `sample-brand` shadowing in every copied video while keeping `node videos/_template/scene.gen.cjs` runnable in place. Cons: a video inside a brand folder cannot override `brand.lock.json` locally without editing `scene.gen.cjs`. Mitigation: per `DESIGN.md` and `014/R2`, per-video palette overrides belong in `palette.json`, never in a duplicate `brand.lock.json`.
- D2. Pros: zero unknown-field notices when building `metricCard` scenes in Lienzo; forwards legitimate group properties (`shot`, `anim`, `tracks`). Cons: explicit destructuring list in `metricCard`. Mitigation: keeps `metricCard`'s single-object `extra` signature backwards-compatible with Spec 015 callers.
- D3–D6. Pros: full support for 4 Lienzo font roles, shot-bound environment layers, held closing titles, shot transitions, and brand font notices with 100% backwards compatibility on existing calls. Cons: slightly wider helper signatures. Mitigation: all new parameters are optional with defaults matching existing behavior byte-for-byte.
